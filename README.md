# DSH 远程控制插件

第三方 **DeepSeek Harness Desktop 插件包**，适配桌面端 **0.2.1-rc.2 / 0.2.1-rc.3**。安装后出现在 DSH 的“已安装插件”列表中，可使用原生开关和卸载按钮管理。

版本：**0.5.2**。插件使用现有 Desktop Host，不创建第二套 Agent 或项目。功能包括设置页、长期访问链接、二维码、设备授权、手机会话抽屉、搜索和连接状态。

这是 **DSH 桌面端插件**，不是独立运行的网页服务。目标环境为 Windows 和上述 DSH Desktop 版本。

[下载原生插件安装包](https://github.com/linbainian/dsh-remote-plugin/releases/latest) · [MIT 许可证](LICENSE)

## 安装

1. 下载 `dsh-remote-aliyun-0.5.2.tgz`，不需要解压。
2. DSH → **插件** → **添加插件** → **安装第三方插件**。
3. 输入该 `.tgz` 文件的完整本地路径，检查包名与版本后安装并启用。
4. 等待插件加载完成；若 DSH 提示需要重启，再正常退出并重新打开桌面端。
5. 打开 **设置 → 远程控制**，首次使用填写自己的 HTTPS 入口、SSH 地址、私钥路径及独立转发端口。

安装包声明 `dsh.bundle` 与 `dsh.client`，并包含运行依赖，不需要用户手动修改 profile 或在源码目录执行 npm 安装。`.zip` 是源码归档格式，不能代替 DSH 的 `.tgz` 插件安装包。

## 开关与卸载

在“已安装插件”中切换 **DSH 远程控制** 的开关。插件使用原生 bundle 热加载流程；停用时释放设置页与后端，并关闭插件自己的网关和 SSH 通道。若所用 DSH 环境提示重启，请按其提示完成。

卸载流程：先在插件页关闭插件，等待停用完成 → 打开插件详情 → **卸载**。若管理器提示插件仍在使用或需要停止 profile，先正常重启 DSH，再删除已停用的插件。

更新插件前也请先关闭插件，等待远程通道退出后再安装新版 `.tgz`，避免 Windows 上运行中的网关占用安装目录。更新完成后再开启插件。

如果旧插件在升级 DSH 后已无法加载，可完全退出 DSH，使用桌面安装目录附带的官方 CLI 更新，再重新打开 DSH。以下路径请替换为自己的安装目录与下载位置：

```powershell
& '<DSH安装目录>\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add '<下载目录>\dsh-remote-aliyun-0.5.2.tgz'
```

停用生效后不再加载远程设置页和后端；卸载从 profile 删除插件包。私有配置、设备记录和长期链接保留在本机，重新安装时可恢复。

## 配置与使用

首次安装不会自动建立公网连接。服务器需要自行准备受信任的 HTTPS 入口，以及代理到 SSH 独立反向转发端口的配置。SSH 使用严格主机指纹校验；使用前先通过可信渠道核验主机指纹并登记到本机 known_hosts。

设置页中的配置只写入 `~/.dsh/remote-aliyun/config.private.json`，Windows ACL 限制为当前用户与 SYSTEM。只保存 SSH 密钥的路径，不读取或上传私钥内容。修改服务器设置前须先停止远程控制。

点击 **开启远程控制**，等待就绪后首次 **生成访问链接**，再使用手机扫码或在另一台电脑打开链接。

- 链接没有到期时间；停止、重新开启或重启 DSH 都不更换访问密钥。
- 只有手动确认 **重置访问链接** 才更换密钥，同时使旧链接和全部设备授权失效。
- 设备 Cookie 默认有效 30 天，到期后仍可使用原链接重新连接。
- 手机端沿用 DSH 的消息、附件、模型、停止任务和审批组件；连接恢复时不自动重发消息。
- 使用期间需要本机在线并运行 DSH。

服务器入口属于使用者自己的配置。安装包不提供公共中转服务器，也不附带任何现有服务器地址、访问链接或凭据。若主动更换服务器入口地址，需要重新复制包含新入口的访问链接。

## 开发

```powershell
npm ci --ignore-scripts
npm test
npm run pack:plugin
```

`npm pack` 将运行依赖打包到 `.tgz`。只打包代码、图标、语言元数据和使用文档，排除本机配置、运行报告、日志和截图。`package.json` 中保留内部包名 `dsh-remote-aliyun` 作为稳定的 bundle 标识。

源码支持 MIT 许可证。代码参照 DSH 插件管理器的实际安装协议；界面与远控职责参考 [ZCode](https://github.com/zai-org/ZCode) 和 [DSH Remote Web Gateway](https://github.com/summer1238/dsh-remote-web-gateway)。本项目并非 DeepSeek 官方插件。

## 验证范围

自动测试覆盖未配置时安全加载、首次配置持久化、长期链接、二维码解码、管理接口隔离、HTTP/WebSocket 代理、撤销断连和 profile 保留。实际插件安装与开关、卸载结果需以 DSH 中的运行验证为准。

24 项自动测试覆盖两个桌面版本的加载与 HTTP/WebSocket 代理。原生插件安装、开关、卸载及重启加载已在 0.2.1-rc.2 验证；0.2.1-rc.3 已完成官方 CLI 更新、重启加载、桌面客户端加载，以及通过自托管 HTTPS 入口读取会话列表和连接 WebSocket 的真实验证。更新保持原有长期链接与设备授权。

0.5.2 修复了旧包把桌面版本写死为 0.2.1-rc.2，导致升级 rc.3 后无法加载的问题。后端现在读取实际运行版本，并检查认证、路由及 Web Host 接口；网关也能读取新版桌面实例状态。版本号不是设备认证依据，原有本机来源限制、令牌和会话校验继续保留。

已核对 0.2.1-rc.3 的客户端服务和设置、移动端扩展点。后续版本即使保留这些接口，也仍需核验实际界面与行为；可加载不代表已经完成所有版本的兼容测试。
